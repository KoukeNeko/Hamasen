Hamasen 哈瑪星 for Linux 1.0.1 is a maintenance release.

## Fixes

- Servers configured to mount at login are now mounted reliably. Previously a single attempt was made shortly after the session started; when the network, VPN or keyring was not yet available, the attempt failed and the server remained unmounted. The application now retries every 15 seconds for up to five minutes, and reports a failure only after the final attempt
- The Start at Login entry now uses the application icon

## Installing

Download `hamasen_1.0.1_all.deb` and install it:

```bash
sudo apt install ./hamasen_1.0.1_all.deb
```

The package is installed over an existing 1.0.0 installation without affecting the server list, settings or stored passwords. An existing Start at Login entry keeps its current command; switching Start at Login off and on again updates it to the installed package.
