# Hamasen Support

For help with Hamasen, bug reports, or feature requests, use either of these
channels:

- Email: [develop@doeshing.uk](mailto:develop@doeshing.uk)
- GitHub Issues: [KoukeNeko/Hamasen](https://github.com/KoukeNeko/Hamasen/issues)

When reporting a problem, please include:

- Your macOS version
- Your Hamasen version
- The connection type you were using
- Steps that reproduce the problem
- Relevant error messages or screenshots

Do not include passwords, private keys, server credentials, or other sensitive
information in an email, issue, log, or screenshot.

Support requests may be submitted in English, Traditional Chinese, or Japanese.
